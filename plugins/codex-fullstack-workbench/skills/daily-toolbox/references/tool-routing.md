# 日常工具路由表

| 任务 | 首选 | 何时升级 |
| --- | --- | --- |
| 搜索代码/文件 | `rg`、语言工具 | 仓库巨大且需要跨会话语义索引 |
| 网页阅读 | 浏览器读取、Markdown 转换 | 需要交互、登录或视觉状态时用浏览器控制 |
| PDF/Office 转文本 | MarkItDown | 需要高保真编辑时用文档专用工具 |
| 表格分析 | CSV/表格能力 | 复杂公式、格式和工作簿关系需专用运行时 |
| UI 检查 | 浏览器 + 截图 | 重复回归时增加自动化测试 |
| GitHub 协作 | Git + GitHub 插件 | 需要远程 Issue、PR、CI 操作时 |
| 错误监控 | 本地日志 | 项目已使用 Sentry 等平台时接入对应插件 |
| 产品行为 | 本地事件检查 | 项目已使用 PostHog 等分析平台时接入 |
| 视频/音频 | FFmpeg | 复杂时间线、批量拼接时用媒体工具 |
| 代码交接 | Markdown 状态摘要 | 长期项目可增加本地记忆/索引，但需可审计 |

## 连接器选择

Gmail/Outlook、Google Calendar/Outlook Calendar、Drive/Box/SharePoint、Slack/Teams、Notion/Atlassian 都是工作流连接器，不是通用开发必装项。只有当资料或动作真实存在于对应系统，且用户接受其数据与权限边界时才安装。

## 安装后验收

- 能否在新任务中发现能力
- 是否需要登录或管理员批准
- 只读与写入操作分别是否可调用
- 一个最小无敏感数据样例是否成功
- 如何禁用或卸载
