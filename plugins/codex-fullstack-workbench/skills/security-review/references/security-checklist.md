# 安全审查清单

## 身份与权限

- 会话固定、Token 验证、过期、撤销和多因素边界
- 对象级与动作级授权、管理员路径、跨租户访问
- 默认拒绝、未知角色和服务账号最小权限

## 输入与执行

- SQL/命令/模板注入、XSS、CSRF、SSRF、开放重定向
- 文件类型、大小、路径遍历、压缩炸弹和内容嗅探
- 反序列化、正则拒绝服务、资源上限和限流

## 数据与供应链

- Secrets、PII、日志、备份、缓存和错误信息暴露
- 依赖锁定、安装脚本、来源、已知漏洞和 CI Token 权限
- Webhook 签名、重放、第三方回调和出站域名限制

## 报告质量

严重级别必须结合可达性、权限、影响和现有缓解措施。没有可复现证据时标注“待确认”，不要夸大结论。
