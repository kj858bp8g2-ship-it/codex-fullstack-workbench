# Security Review

以资产、信任边界和攻击路径组织审查。不要只运行扫描器，也不要用扫描器缺少告警证明安全。

## 工作流

1. 确认审查范围、入口、资产、攻击者能力与信任边界。
2. 定向检查认证、授权、输入处理、输出编码、文件/路径、请求转发和敏感数据。
3. 检查仓库 Secrets、配置默认值、日志、错误响应、依赖来源和 CI 权限。
4. 验证浏览器、API、数据库和后台任务是否执行同一授权规则。
5. 运行适用的静态、依赖或秘密扫描，并人工确认高风险结果。
6. 按 [references/security-checklist.md](references/security-checklist.md) 分级报告可利用路径、证据和修复建议。

## 安全边界

- 不读取、回显、提交或持久化真实凭据。
- 不在未获授权的系统执行利用、探测或破坏性验证。
- 不自动升级权限、修改生产策略或轮换凭据。
- 发现疑似秘密时只报告文件位置与类型，遮盖具体值。

## 输出

按严重级别给出：位置、前置条件、攻击路径、影响、证据、修复和验证方法；将误报或未知项单列。
