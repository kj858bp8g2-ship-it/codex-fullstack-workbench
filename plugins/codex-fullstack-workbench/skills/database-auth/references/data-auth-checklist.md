# 数据库与授权清单

## 数据模型

- 主键、唯一约束、外键、非空和检查约束是否表达业务真相？
- 时间、货币、时区、软删除和审计字段语义是否清楚？
- 多租户数据是否在每条访问路径上绑定租户？

## 查询与迁移

- 对真实量级检查查询计划，而不是只看小样本速度。
- 分页有稳定排序；索引与过滤、连接和排序相匹配。
- 大表变更考虑锁、回填批次、双读/双写窗口与旧版本兼容。
- 回滚不能恢复数据时，提供备份或前向修复方案。

## 认证与授权

- 明确主体、会话、角色、资源和动作。
- 检查对象级授权、租户隔离、RLS/策略默认拒绝和管理员边界。
- Token 有受众、过期、撤销和存储策略；Cookie 设置安全属性。
- 权限测试至少包含允许、拒绝、跨租户和未知角色。
