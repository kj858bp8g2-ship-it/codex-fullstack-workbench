# 文档摄取指南

## 推荐流程

1. 检测 `markitdown --version` 或 Python 模块是否可用。
2. 将输出写到用户指定目录或临时目录，保留原始扩展名信息。
3. 用标题与关键词定向搜索，不默认把整个转换结果放进对话。
4. 引用结论时记录原文件名以及可用的页码、幻灯片、工作表或章节。

## 格式注意

- PDF：文字顺序、页眉页脚、扫描页和多栏布局可能失真。
- Word/PowerPoint：文本可提取，但复杂布局、批注和动画不能视为完整保留。
- Excel：确认工作表、单位、公式值与隐藏区域；转换文本不等于计算审计。
- 图片/扫描件：OCR 需人工核对名称、数字和表格。
- 音频/视频：通常依赖额外转写组件或 FFmpeg，失败时报告缺失依赖。

## 输出命名

建议使用 `<原文件名>.md` 或 `<原文件名>.converted.md`。不要在源资料旁生成可能被误提交的敏感文本，除非用户明确指定。
