# 交付与发布门禁

## 变更完整性

- Diff 只包含用户请求、确认假设或必要验证
- 没有 TODO、调试输出、临时报告、秘密、机器绝对路径或客户数据
- 文档、版本和迁移说明与行为一致

## 验证

- 目标回归测试已 RED→GREEN
- 类型、Lint、相关测试、构建和 UI 检查按风险完成
- 外部服务、不同平台和生产路径的未验证范围已列出

## 发布准备

- 配置与环境变量清单不包含值
- 迁移顺序、兼容窗口、监控信号和回滚条件明确
- 变更说明面向使用者，不只复述文件名
- Commit/PR/发布/部署分别获得所需授权

## 交接模板

```text
完成：
用户可见变化：
关键文件：
已验证：
未验证：
风险与回滚：
下一步：
```
