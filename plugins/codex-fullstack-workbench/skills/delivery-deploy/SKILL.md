# Delivery and Deploy

本 Skill 负责交付准备，不默认授权提交、推送、创建 PR、发布或部署。

## 工作流

1. 读取 Git 状态和 Diff，区分本次改动、用户原有改动和生成物。
2. 对照请求审查范围、正确性、安全、兼容性和无关改动。
3. 运行与风险匹配的测试、类型、Lint、构建及必要的真实界面验证。
4. 确认配置、迁移、功能开关、监控、回滚和部署顺序。
5. 清除临时输出并扫描秘密、绝对路径与客户数据，但不删除用户文件。
6. 按 [references/release-gate.md](references/release-gate.md) 生成交付说明。
7. 只有用户明确授权后，才执行提交、推送、PR、发布或部署。

## 结论语言

- “本地验证通过”只表示列出的本地命令。
- “可供审查”不等于“生产就绪”。
- 未执行真实认证、第三方调用、迁移或部署后检查时必须明确说明。

## 输出

列出改动文件、用户可见行为、验证结果、未验证项、部署/回滚要求、风险和下一安全动作。
