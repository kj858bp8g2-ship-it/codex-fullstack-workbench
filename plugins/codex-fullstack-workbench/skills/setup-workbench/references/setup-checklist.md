# 工作台检测清单

## 项目事实

- 根目录、Git 分支和未提交变更
- 最近适用的 `AGENTS.md`
- README、包管理器、锁文件、运行与测试命令
- 语言、框架、数据库、部署目标与 CI
- 已有 `.agents/skills`、`.codex` 或同类配置

## 环境事实

- 操作系统与 Shell
- `git`、项目运行时、包管理器和容器工具是否可调用
- Codex CLI 或桌面应用入口是否可用
- 文档转换、浏览器验证等本地工具是否存在

## 安全边界

- 不读取或回显密钥内容；最多报告变量名是否存在。
- 不自动执行登录、OAuth、云资源创建、数据库迁移或生产部署。
- 不覆盖同名文件；只有显式强制时才先备份再替换。
- 不将用户绝对路径、客户数据或运行日志写入可发布模板。

## 推荐顺序

1. 本插件的项目规则和核心 Skills
2. 与当前技术栈直接相关的一个能力插件
3. 实际使用的协作、数据库和部署服务
4. 生产监控与分析
5. 特定项目才需要的媒体、移动端或知识管理能力
