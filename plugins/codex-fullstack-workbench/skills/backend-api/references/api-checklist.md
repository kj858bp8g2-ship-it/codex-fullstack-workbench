# API 设计与审查清单

## 契约

- 方法、路径、内容类型和版本策略
- 输入类型、大小限制、默认值和未知字段处理
- 正常响应、分页、空结果与错误结构
- 向后兼容、弃用和客户端升级路径

## 可靠性

- 超时、取消、重试、退避和熔断
- 幂等键、去重、并发冲突和事务边界
- 队列的投递语义、死信和重放
- 缓存键、失效、陈旧数据与租户隔离

## 安全与观测

- 身份验证、对象级授权、速率限制和滥用保护
- 日志脱敏、关联 ID、指标和告警信号
- Webhook 签名、时钟偏差、重放保护
- 外部错误不得泄露内部堆栈、SQL 或秘密

## 验证

覆盖正常、无权限、无效输入、重复请求、并发和依赖失败。对真实外部系统未验证时明确说明。
